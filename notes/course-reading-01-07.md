# 第 01–07 课：初轮学习记录

来源：影视飓风（MediaStorm）付费剪映教学课程，本文件为非官方原创学习归纳。
证据：本轮已读各课全部 AI 字幕；仅指定时间点画面已核对，未完成音轨听辨及连续运动复核。不是最终 Skill。

## 01｜课程定位

- 00:19–01:11：课程强调节奏、信息组织、画面与声音文字的配合；软件功能只是落地手段。因此后续技能应能说明“为什么这样剪”，不能只列按钮或命令。
- 01:11–01:29：讲师说明课程配套音乐和素材。该口头说明不直接构成本仓库分发素材的许可；素材不进入 Skill 包。
- 字幕存在课程名、栏目名误识别；本文件不把这些误字写作正式术语。

## 02｜学习环境与资产准备

- 00:22–01:59：按进度下载练习素材、集中管理，先熟悉软件与素材，再进入剪辑。
- 01:59–02:47：素材、预览、参数、时间线的四区布局；课程采用 Final Cut Pro 快捷键预设，不能把演示快捷键硬当所有剪映安装的默认值。
- 03:02–03:40：素材移动后通过重链接恢复；容器扩展名不足以判断能否解码，遇到导入问题需检查实际编码。
- 03:40–04:17：性能问题可从缓存、后台任务、预览负担排查；实施缓存清理时应区分可重建缓存与原件、草稿。
- 04:17–05:03：课程介绍同账号云同步。未来 Skill 可说明使用路径，但不能自动上传私有项目。

## 03｜基本成片与时间线逻辑

- 03:15–05:28：以帧为单位定入出点；先找可用区间，再分割删除不稳定首尾。导入、分割、删除、排列构成最小剪辑闭环。
- 05:39–07:33：横向是播放次序，纵向是叠加关系；自由层级、主轨磁吸会改变编排行为，操作前需确认工程设置。
- 08:04–09:32：把背景音乐和镜头切点建立关系；自动踩点的密度是候选坐标，不等同于已经完成艺术节奏判断。
- 09:32–10:29：先降低预览负担，需要时使用代理；课程说明最终导出回用原始素材。实际交付仍要检查媒体在线和导出来源。
- 10:29–11:10：导出参数由素材与目标共同决定。00:10:50 单帧显示的是 4K / 60 fps / HEVC / PCM / 48 kHz 的演示设置；它不是所有项目的通用预设。
- 待回查：字幕提到导出参考表的确切出现位置，当前 00:10:50 画面是导出界面而非表格。

## 04｜口播、气口与 A-roll / B-roll

- 01:25–02:50：草稿、下载素材和缓存应放在有规划的位置；素材分类先服务检索和复用。00:02:40 抽帧尚未拍到分类表，仍需回查。
- 03:01–04:39：波形能定位停顿候选，但重复、口误与表达完整性需要语义判断；不能见到低音量就直接删除。
- 04:39–06:29：智能剪口播用于加速粗剪，保留表达需要的呼吸和停顿。剪点过紧时可调整间隔、短叠化并铺房间底噪；具体听感未验，暂不写固定淡化时长。
- 06:29–08:59：A-roll 承载主要信息，B-roll 补充说明；将候选 B-roll 横铺在第二时间线可加快检索。CLI 实现时应保留这类“先浏览候选，再挑可用区间”的逻辑，而非模仿界面布局。
- 08:59–10:56：B-roll 长度对齐完整语义，镜头尽量成组；裸露跳剪可用相关补充画面或有意的景别变化处理。课程建议将需静音的 B-roll 集中，但有叙事价值的同期声应另外判断，不把所有补充镜头永久静音。
- 10:56–12:59：补录优先改善录音距离和环境；后期再做一致性处理；耳机检查左右声道是否齐全。统一响度不等于所有片段使用相同增益。
- 12:59–14:28：尽量在加入 BGM 前识别对白字幕；校正错字并核对平台 UI 安全区。原字幕中的“漏字”可能指露出 A-roll 的短暂画面，需音画回查，不按字面定论。
- 00:13:53 画面核对：演示字幕阴影面板为黑色、90% 不透明度、15% 模糊、距离 5、角度 -45°；是案例设置，不作为统一标准。字体、字号与位置仍待其他画面核对。
- 14:28–15:26：音乐长度适配成片，末尾淡出避免硬断；最终仍需实际听感验证。

## 05｜混剪与镜头关系

- 01:02–02:51：无对白主线时，从素材共同特征、景别与音乐段落建立框架。先决定观看节奏，再选择与之匹配的画面。
- 03:18–04:16：舒缓铺垫可配较平稳镜头；远景到中景到细节是一种空间组织方法，不是必须套用的固定顺序。
- 04:16–05:13：匹配剪辑关注形状、位置、运动轨迹等跨镜头联系；转场理由应能在素材中找到。
- 05:13–07:04：并置会改变观众对镜头的理解。写技能时需要检查组合产生的叙事含义，尤其不能无意制造错误因果。
- 07:04–08:46：均匀卡重拍容易被预期；可通过切分、抢拍或延迟改变节奏，但实际有效性依赖音乐与画面，当前没有听验。
- 08:46–10:59：转场用于关键转折，特效用于强调氛围；先验证素材与组接成立，再决定是否需要特效。预设名称与可用性需要当前剪映或 CLI 枚举确认。
- 待验：01:58–02:23、07:42–08:39 等演示段存在对白少或无对白区间，不能只靠字幕重建剪辑效果。

## 06｜音乐裁切与声音叙事

- 00:39–03:43：在音乐合适重拍处收束；若尾音被片段边界截断，课程通过延长容器时间、复合片段和回声/混响保留衰减，再只接入需要的尾迹。未来可在音频工具中实现相同目标，必须验证尾迹没有被再次截掉或重复主体音乐。
- 03:43–05:22：从画面联想环境声，用声音先行建立场景预期；课程示例海浪提前约 2–3 秒，不是所有 J-cut 必须提前的固定数值。L-cut 则让上一画面的声音延续。
- 05:22–07:16：rise、低频等设计音效可改变期待、强化动作和转折；应说明叙事目的，避免为“有动静”而堆叠。
- 07:16–08:24：包含前后对比与成片播放，必须另做听辨，字幕不能证明改进效果。
- 08:24–09:34：建立可检索且许可清晰的音效库；AI 音效为候选来源，不是成片质量保证。00:08:30 画面展示的是音效库目录与试听窗口，未读到资源站表。
- 09:34–10:51：可从生活录音通过变速、变调、叠层、混响形成设计声音；具体参数由听感决定。
- 待核对：字幕中 `sub 或 drum` 的第二个英文词疑似识别有误，不直接写成标准术语。

## 07｜导出、版本和发布

- 00:52–02:21：单独选封面，画面简洁且代表内容；首帧可能黑场，不应默认用首帧。文件内封面与平台发布页封面是否一致需另验。
- 02:21–05:03：文件名携带日期、片名、分辨率、版本和用途；项目归档要含素材与工程。把目录整体移动并不保证绝对路径自动恢复，实际迁移后仍须测试重链接。
- 05:03–07:53：分辨率不虚构源素材细节，帧率先考虑草稿与原片；24/25/30/60 fps 是场景选择，不等同于平台硬规则。
- 07:53–09:09：AI 超分与补帧会产生纹理伪影、过度平滑与运动错误；逐段补救并检查，不能代替前期质量。
- 09:09–10:59：码率与复杂度、帧率、分辨率、编码效率有关；极高码率不能保证平台二压后更好。课程经验和平台当前限制应分开记录。
- **00:10:38 画面核对的重要歧义**：表格的码率单位印为 `KB/s`，数值为万级，而视频码率通常以 bit/s 表达。此处只记录“课程表单位待核实”，不把表格数值直接变成 FFmpeg 参数，更不将其当成平台官方要求。
- 10:59–11:56：区分容器和编码器；H.264 为课程建议的兼容性起点，HEVC 可提高压缩效率，但设备兼容与速度需实测，不能保证固定节省比例。
- 12:22–13:55：课程介绍 AAC 不同档位、PCM、48 kHz。字幕的 `A c` / `H64` 等误字按画面和语境保留待核，不照抄成正式格式。
- 13:55–14:20：导出前检查会员素材或功能依赖；不把当时限免、订阅条件写成永久事实。
