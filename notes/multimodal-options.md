# 完整音画学习的接口方案调查

调查日期：2026-10-26。本文为工具方案评估，不是影视飓风课程内容或官方推荐。仅查询了公开文档；未调用候选模型、未上传课程、未产生模型调用费用。

## 结论与选择条件

**优先候选是原生音画云端接口，先通过小范围试点再决定是否覆盖全课程。** Gemini API 和阿里云 Qwen-Omni 都有官方视频含音轨输入路径；是否适合本课程仍需实际验证。本地 Omni 是保留课程不出机的候选，但本机空间和同步处理链路尚不满足试装条件。

| 路线 | 文档已确认的能力 | 尚需验证 | 当前可执行状态 |
| --- | --- | --- | --- |
| Gemini API | 视频与声音理解、时间定位、可配置帧采样 | 中文剪辑语境、音效/音乐判断、快速动作和界面小字；账户地区及模型权限 | 可准备试点，课程上传和费用尚未授权 |
| 阿里云 Qwen-Omni | 视频文件含原音轨输入；按模态计量 | 具体地区模型、采样上限、短促动作、时间戳精度和数据处理条件 | 可准备试点，课程上传和费用尚未授权 |
| Mac / MLX Omni | MLX-VLM 的 MiniCPM-o 有图像、音频及联合输入例子 | 按时间同步的视频和音轨是否完整传入、量化质量、峰值内存与长片分段 | 仅文档候选，未安装或推理 |
| 本地或自有 GPU 上的 Qwen Omni | 官方代码明确支持提取视频内声音并联合输入 | 硬件资源、运行环境、吞吐与片段精度 | 未发现可直接使用的已验证服务 |

“视频理解”普遍仍使用帧采样；接受 MP4、完成一次调用或模型自称看完，都不足以证明覆盖了每帧、所有声音或全部教学细节。

## Gemini API

官方文档支持包含音画细节的分析和时间定位。默认静态视频处理为 1 fps；可以设置自定义采样率。快速动作可能遗漏，需短片加密采样及原帧回查，不能用默认采样验收两帧动画。可用模型示例为 `gemini-3.8-flash`，具体权限需在实际账户确认。[视频输入文档](https://ai.google.dev/gemini-api/docs/video-understanding)

音频接口描述的任务包括声音描述、对白、语气和音乐情绪，超出 ASR 转文字范围；这些是产品能力说明，尚未成为本课程实测证据。[音频文档](https://ai.google.dev/gemini-api/docs/audio)

本课程 13,315.18 秒，按文档静态视频估算：低分辨率每秒约 66 个图像 token 加 32 个音频 token，合计约 130 万输入 token；常规每秒 258 加 32，约 386 万。以调查日 Flash 标准输入价 $0.75/百万 token 计算，**基础输入约 $0.98–2.90**。这是算式估计，未含文本、元数据、输出/思考、重试、重复片段或提高采样率；不是最终账单或预算授权。调用前必须重新核价并设置总预算。[视频计量说明](https://ai.google.dev/gemini-api/docs/video-understanding)、[价格表](https://ai.google.dev/gemini-api/docs/pricing)

免费服务通常会将输入/输出用于产品改进，且可能有人工作业；付费服务条款规定不将这些内容用于产品改进，但仍有安全等有限保留。不能把“付费”解释为绝不留存。课程资料不应为节省费用而默认投到免费服务。[数据使用条款](https://ai.google.dev/gemini-api/terms)

Files API 支持主动删除，文档称文件自动在 48 小时后删除；这只说明文件资源生命周期，不能替代前述服务数据条款。[文件管理](https://ai.google.dev/gemini-api/docs/files)

## 阿里云 Qwen-Omni

官方文档明确区分“含音频的视频文件”和纯图像列表。前者可进入音画分析；后者不能单独证明听过原音轨。调查日文档列出 `qwen3.8-omni-flash` 等型号，视频与音频分别计量。其估算代码使用 2 fps，并有帧数与像素预算；课程快速效果仍需要单独复核。[输入、限制与计量](https://www.alibabacloud.com/help/en/model-studio/qwen-omni)

本地 Base64 输入仍是向云端上传，不是离线推理；该路径编码后需小于 10 MB，长课需分段或采用其他受控文件输入。不应为适配 URL 示例把课程放到公开地址。模型、价格、API Key 和端点按地区核对，不能拿某一地区单价承诺另一地区费用。[接口说明](https://www.alibabacloud.com/help/en/model-studio/qwen-omni)、[区域价格](https://www.alibabacloud.com/help/en/model-studio/model-pricing)

官方隐私页说明不用于模型训练，同时说明会存储调用数据。[隐私说明](https://www.alibabacloud.com/help/en/model-studio/privacy-notice)

国际站保留策略默认不超过 30 天，存在安全/法律例外，有状态文件另计；该页面的 ZDR 列表没有列出本次候选 Omni 系列。不能因为工作区启用了 ZDR 就宣称这些调用零保留，也不能将国际站条款直接外推到国内站账户。[国际站保留政策](https://www.alibabacloud.com/help/en/model-studio/data-retention-policy)

## 本地候选和本机约束

本机为 Apple Silicon、24 GiB 统一内存；调查时可用磁盘约 655 MiB，期间会随系统运行变化。没有清理其他项目，也没有下载新的 Omni 权重。

Qwen2.5-Omni 官方 Transformers 表中，3B BF16 的 15 秒视频理论 GPU 内存为 18.38 GB，60 秒为 28.22 GB，且说明实际常更高。该表基于特定注意力实现，不能直接当作 Metal 内存保证。3B/7B 量化可另调查，但“权重较小”不代表音画编码器、缓存和上下文都放得下。[官方资源与音轨开关](https://github.com/QwenLM/Qwen2.5-Omni#minimum-gpu-memory-requirements)

Qwen3-Omni 的官方 BF16 表更高：Thinking 的 15 秒视频理论约 68.74 GB。无需生成语音仍不能将其按“只激活 3B”估成 3B 常驻模型。官方视频评测使用 2 fps；推理链需一致启用 `use_audio_in_video`，否则不能声称理解了视频声音。[官方说明](https://github.com/QwenLM/Qwen3-Omni#minimum-gpu-memory-requirements)

MiniCPM-o 4.5 官方给出音画分段和时序交错的 Omni 示例；MLX-VLM 的对应集成页则明确演示图像、音频及联合输入。目前未验证该 Mac 集成能完整复现官方同步视频路径，应先做合成素材测试，不能仅因它叫 Omni 就标为可用。[MiniCPM-o 官方说明](https://github.com/OpenBMB/MiniCPM-V/blob/main/docs/minicpm_o4dot5_en.md)、[MLX 集成](https://github.com/Blaizzy/mlx-vlm/blob/main/mlx_vlm/models/minicpmo/README.md)

本地路线下一步需要可用存储位置、权重体积及可重复的同步输入测试；优先单独环境，不改变已可用的 ASR 环境。暂不承诺安装后就能完成课程验收。

## 可复核的试点流程

1. **先测自制素材**：含已知时间点的闪帧、运动、提示音、混响尾音和左右声道变化。比较音画联合、仅画面、仅声音三种输入，确认模型没有只复述文字。若路径转为单声道，左右声道验收需另做。
2. 通过基础测试后，再针对 [待验清单](../progress/remaining-review.md) 选课内小片段；云端处理前明确提供商、账户地区、上传范围、保留方式和总费用上限。
3. 第一轮不给现有字幕或笔记结论，要求返回带时间码的声音事件、镜头/运动变化、界面文字与不确定项；第二轮再做字幕对照，降低照抄已有描述的可能。
4. 快速效果使用独立短片、足够采样及逐原帧回查；音效前后对比保留原声。不能把静音减速视频的运动复核当作原速节奏听验。
5. 逐请求记录源哈希、原始时间范围、音轨是否传入、帧采样/分辨率、返回截断、模型标识、用量与复核结果。请求成功但返回不完整时保留缺口。
6. 试点通过后才覆盖全部 18 课：短段连续覆盖，边界保留重叠；核对并集无遗漏，再复核无对白演示及快速效果。覆盖提交不等于语义理解，仍要审核输出是否抓住实际教学变化。

只有全课程各时间段的音轨和连续画面证据齐备、疑点已处理，才更新完整学习状态并开始最终子 Skill 分类。当前授权仅为调查；不执行课程上传、付费调用或新模型下载。
