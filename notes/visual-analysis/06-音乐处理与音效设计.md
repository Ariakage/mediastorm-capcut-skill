## 一、本课定位

这是第 05 课的**声音续篇**，片头烧录标题为“**第四节课：听觉塑造｜音乐处理与音效设计思维**”。课程直接打开上一课的 41 秒混剪工程，继续在同一时间线上做四件事：

1. **音乐裁切**：在副歌结束的重拍处切开，删掉后面的段落；
2. **尾音处理**：用复制 + 静音 + 复合片段（Mac `Option+G` / Windows `Alt+G`）+ 回音/混响，制造自然的衰减尾迹，再二次修剪，只保留尾迹；
3. **音效设计**：环境音（海浪）、设计音效（Rise、低频 Drone）、J-cut / L-cut；
4. **音效库与原创音效**：剪映自带音效库、四个专业资源站、AI 音效、自己录音后用变速/变调/叠层/混响改造。

主要界面是桌面版剪映的音频参数面板、时间线、音效库；也出现手机端剪映、Finder 文件列表、一个专业音效管理软件（界面显示 `mediamonks.studio`、`Transfer Logs`、`FOUNTAIN_Laps...` 等条目）。本课没有导出成片，结尾明确说下一课才讲导出。

## 五、可提炼的剪辑知识

- [画面] **音乐裁切**：先在波形上找副歌结束的重拍/峰值，在那里精准切开，再删除后段。不是直接淡出了事。
- [画面] **尾音处理**：复制两段音乐 → 第二段静音 → 拖到原片段后面 → 选中两段 → `Option+G`（Mac）/ `Alt+G`（Windows）封装为音频复合片段 → 在“声音效果”里选“回音”（或大厅混响）→ 二次修剪，只保留从切点开始向后扩散的尾迹 → 把尾迹接在正常音乐之后。
- [画面] **复合片段的作用**：把多段音频打包成一个更长的“容器”，让软件以为音频还没结束，从而给回声/混响留出扩散空间。没有这一步，直接在已截断的音频上点回音“没有用”。
- [画面] **J-cut**：声音比画面提前 2–3 秒出现，并加渐入；轨道上形成 J 形。用于建立场景预期、消除剪辑痕迹。
- [画面] **L-cut**：画面消失后声音继续；与 J-cut 相反，也是声音/画面错位的手法。
- [画面] **设计音效**：Rise 类用于开场、转场、动作强化；低频/Drone 类用于缓慢推进的空镜，制造紧张/超现实氛围。每个音效都应服务叙事，不能为“有动静”而堆叠。
- [画面] **腾出黑屏**：用“向右全选”工具（快捷键 `]`）选中鼠标后面的所有片段，整体后移 1–2 秒，再把 Rise 音效放进黑屏。这样开场声音先于画面，拉高预期。
- [画面] **音效库**：剪映自带音效库可按关键词搜索；专业资源站包括 Musicbed、Artlist、Storyblocks、Envato Elements；本地按“音效/BGM”两级文件夹整理，文件名体现用途（如“人名条动效”“过场标题”“高能预警”）。
- [画面] **AI 音效**：选中视频段落后生成三条候选，每条约 3 秒；课程称当时为 VIP/限免。它是候选来源，不是成片质量保证。
- [画面] **原创音效**：用手机/录音笔近距离录金属杯、钥匙等生活物件；导入剪映后降速（演示中 1.00x → 0.58x → 0.19x → 0.26x）、打开“声音变调”、复制一层并给第二层加回音/大厅混响，两层叠成定制音效。
- [字幕] 讲师反复强调：音效不是“配音”，它在参与叙事；每个音效都要认真斟酌，否则会适得其反。
- [推论] 对 Skill 的启示：应把“音乐裁切 → 尾音容器 → J/L cut → 环境音 → 设计音效 → 资源库 → AI/原创”写成一条声音设计流程，并明确“听感判断必须由人完成”。
- [待验] 所有涉及听感的结论（“闷闷的”“自然得多”“惊艳”“机械感”）都没有经过听辨；回音/混响参数、J-cut 精确提前量、原创音效最终倍速，都需要连续音画或工程文件复核。
