# 全课程关键发现与差异修正

来源：影视飓风（MediaStorm）付费剪映教学课程，个人学习整理，非官方。
方法：18 课全部按 **2 秒间隔**抽帧，组成 2×2 时间码索引页逐张查看；界面参数用全分辨率定点抓帧和局部裁剪复核。逐课细节见 [索引](README.md)，合并全文见 [全课程细粒度画面解析](全课程细粒度画面解析.md)。

## 一、覆盖与边界

- 18 课、6,656 个采样帧、1,658 张索引页；分课文档合计约 4,600 行。
- 这是**静态画面抽样**：不是逐帧解码，不是连续视频输入，也没有音轨听辨。
- 所有参数都是课程录制时的界面状态或案例值，不是通用预设、平台规则或永久功能。
- 截图、索引页和原始视频都在被忽略的 `cheese/` 下，不进入 Git。

## 三、全课程知识主线

画面证据支持的课程结构，不是按按钮分类：

1. **准备与最小闭环**（02–03）：安装登录、素材目录、四区界面、FCP X 快捷键预设；导入 → 选片 → 逐帧定位 → 分割删除 → 轨道排列 → BGM → 踩节拍 → 代理 → 导出。
2. **口播与 B-roll**（04）：波形找候选 → 两刀删中间 → 智能剪口播做第一轮 → 气口叠化/底噪 → A/B-roll 分工 → 补录/响度/声道 → 字幕安全区。
3. **无对白混剪**（05）：景别框架 → 音乐坐标 → 双时间线筛候选 → 卡点/抢拍 → 匹配剪辑 → 并置含义 → 转场/特效边界。
4. **声音设计**（06）：重拍处裁音乐 → 复合片段 + 回音保留尾迹 → J/L-cut → Rise/Drone 设计音效 → 音效库与原创音效。
5. **交付**（07）：封面 → 命名/归档 → 分辨率/帧率 → AI 超分/补帧 → 码率/编码/音频 → 会员素材检查。
6. **运动与变速**（08–09）：缩放/位置关键帧 → 三参数曲线统一缓动 → 常规变速/曲线变速 → 源帧率与补帧风险。
7. **合成**（10）：按素材类型选智能抠像/自定义抠像/色度抠图/蒙版/混合模式 → 抠像三明治 → 沿运动检查。
8. **调色**（11）：识别 Log/色域 → 匹配技术 LUT → 基础/HSL/色轮 → 示波器 → 独立调节层 → 参考静帧。
9. **综艺包装与跟踪**（12–13）：信息密度决定镜头长度 → 价格阶梯 → 文字跟踪只保留位置 → 数字闪变 → 上下场配对 → 平面跟踪四角/参考帧/目标消失处理。
10. **多机位与长视频结构**（14–15）：合板同步 → 多机位粗剪 → 角标/金句 → 长视频分段 → 波峰制 → 时钟图检查 → 计时器包装。
11. **Vlog 与色彩统一**（16）：目录命名 → 智能镜头分割拉片 → 乱序思维导图 → 旁白/节奏点串联 → RGB 曲线 → 色彩克隆。
12. **AI 与手机**（17–18）：智能粗剪提示词 → 文生视频模型/积分 → 手机 AI 初版 → 固定播放头 → 轨道折叠 → 手机导出表 → 草稿云同步/扫码回传。

## 六、跨课归属修正（对 Skill 分类很重要）

- **第 08 课只讲关键帧、缩放/位置参数与曲线缓动**；全课 82 张索引页没有“点跟踪标签、数字闪变、计时器”。这些内容分别在第 12 课（文字跟踪、设备标签、数字闪变、上下场动画）和第 15 课（计时器包装）。此前把三者都归到“运动控制”的写法需要改。
- **第 13 课才是平面跟踪**；第 12 课是点跟踪/文字跟踪。两者入口和自由度不同，不能合并成“跟踪”一个概念。
- **第 05 课是混剪/蒙太奇**，第 06 课是它的声音续篇；两课共用同一 41 秒工程，引用时应成对出现。
- **第 12 课包含“导出回导做性能烘焙”**，这是跟踪工作流的一部分，不是第 07 课的交付导出。

## 七、可复算/可复核的关键数值

- **03 首段裁剪**：源 `00:00:30:17`，切头 `00:00:03:08`，切尾约 `00:00:24:17`，保留 `00:00:21:09`。
- **04 字幕阴影**：不透明度 90%→59%，模糊 15%→7%，距离 5，角度 -45°；模糊先变、不透明度后变，68% 是拖动中间值。
- **04 音频**：波形占比 60%；气口叠化提示 0.1s；声道配置三选项；导出 3840×2160 / MOV / 30fps / 50000 Kbps / H.264 / AAC 320 / 48kHz，估计 583MB。
- **07 导出表**：抖音 1080p–4K/30/推荐/20000–35000 KB/s；小红书 1080p–4K/30/推荐/10000–25000；B站与 YouTube 2K–4K/60/更高/40000–45000；单位为 `KB/s`，与面板 `Kbps` 不一致。
- **10 色度抠图**：默认 `强度20/阴影0/羽化0/清除0` → 最终 `43/31/7/26`；混合模式 11 项，变亮组含强光。
- **11 调色**：HSL 绿色 色相 +100、饱和度 -28；基础亮度 -25/+50 演示；色轮高光 `0.18/-0.02/-0.38 → 0.41/0.22/-0.15`。
- **12 包装**：镜头 1.2/1.2/2.2/2.2/3.3/4.2 秒；文字跟踪关闭“缩放/距离”；数字闪变约 2 帧/段、8–10 段；出入场约 0.4s。
- **15 计时器**：矩形蒙版 538×540、圆角 27、白色描边 2、阴影 100/19/0/0、画面不透明度 45%；文字字号 15、缩放 134%、文本阴影 45/16/0/0；动画面板读数 0.5s。
- **16 调色**：RGB 曲线 S 形；色彩克隆/智能调色强度 80；LUT 强度 100、肤色保护 0；导出 4K/MOV/30fps/AI 补帧开。
- **17 AI**：Seedance 2.0 Fast / Mini / 1.0；分辨率 480p/720p；积分读到 200/1070/856；Seedream 5.0 图片；豆包 Pro / DeepSeek-R1 文本。
- **18 手机**：AI 初版 3:4、5 个候选；导出 1080P/30fps；平台表逐格见第 18 课文档；草稿 246.8MB → 127.3MB。

## 八、对组合 Skill 的启示

1. **先判断，再操作**：课程反复把“为什么这样剪”放在按钮之前；Skill 应保留判断链和失败条件，而不是复刻界面步骤。
2. **轨道/时间线是共同底层**：主轨磁吸、自由层级、复合片段、调节层、多机位、平面跟踪都改变“片段属于谁、时间如何映射”；写入任何 CLI 脚本前先确认这些前提。
3. **声音不能靠画面替代**：本轮回看只能确认波形、轨道位置、参数名和口型/动作的静态关系；音乐、音效、语气、混响、声道仍待听辨。
4. **参数必须带上下文**：45% 透明、0.5s 动画、19 阴影、50000 Kbps、4K/60fps 都是案例值；Skill 里应写成“按素材/目标/平台核对”，不能写成固定预设。
5. **AI 是候选生成器**：智能粗剪、文生视频、手机 AI 初版都以“候选 → 人工筛选/精修”出现；不能把生成结果当最终交付，也不能替用户消费积分。
6. **交付边界要分开记录**：草稿结构检查、FFmpeg 代理预览、剪映界面打开/保存、最终听视觉验收是四种证据，不能互相替代。
