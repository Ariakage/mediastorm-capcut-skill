## 一、本课定位

这是一节**导学 / 环境准备课**，不是剪辑技巧课。全片主线是：

1. 下载安装剪映并登录；
2. 从影视飓风官网按课节下载素材包，建立统一素材目录；
3. 认识剪映的四区界面、布局调整、Final Cut Pro X 快捷键预设；
4. 检查网络、缓存、后台应用等运行环境；
5. 处理素材丢失、格式不支持等常见问题；
6. 用剪映云在多设备间同步草稿。

画面中真正出现剪映操作界面的时间是 01:50–02:42，且只打开了一个空白“导学课”工程，**没有在时间线上做任何剪辑操作**。其余大量画面是讲师口播和插画式演示，插画里的深色剪辑软件不是剪映。

课程结构在本课首次以卡片形式出现：**四个部分（基础篇 / 进阶篇 / 实战篇 / 加餐篇）、14 节正课 + 4 节加餐课**，与第 01 课宣传片里的结构板一致。

## 五、可提炼的剪辑知识

- [画面] 课程结构是四部分、14 节正课 + 4 节加餐；本课属于“准备阶段”，不承担具体剪辑手法。
- [画面] 演示软件为**剪映专业版**（登录弹窗与主页标志均为“剪映”），主要在 macOS 上操作；Windows 侧只出现官网 `.exe` 安装器画面。
- [画面] 编辑界面四区：素材面板、播放器、参数属性面板、时间线；布局可换、面板边界可拖拽。
- [画面] 课程使用 **Final Cut Pro X** 快捷键预设；这是课程选择，不是剪映的默认或唯一方案。
- [画面] 草稿参数至少包含：草稿名称、保存位置、导入素材方式（复制至草稿 / 保留在原有位置）、色彩空间、浮点链路、自由层级、代理模式、时间线名称、比例、分辨率、帧率。

- [画面] 缓存可手动清除，也可设为自动删除 N 天前的缓存；自动备份可单独开启。
- [画面] 云同步路径：同账号多端登录 → 电脑右键草稿“上传至云空间” → 手机“我的云空间”下载 → 继续剪辑。

- [待验] 本课没有实际时间线操作，不能从本课提炼剪点、节奏或转场方法。
