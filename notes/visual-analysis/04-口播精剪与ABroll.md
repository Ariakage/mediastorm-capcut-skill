## 一、本课定位

这是一节**完整口播视频的实操教学**，主要演示 macOS 版剪映专业版（全局设置菜单右下角可见“版本 10.3.0”）。课程从工程设置、素材分类开始，依次完成：口播粗剪 → 智能剪口播 → 气口修补 → A-roll/B-roll 编排 → 音频补录与响度/声道处理 → 字幕识别与样式 → BGM → 导出。

画面中同时存在三类素材，需要区分：

- **讲师机位**：Tim 穿浅灰卫衣，坐在书架与柔光灯前，是全片的讲解画面。
- **课程 A-roll 演示素材**：时间线中的 `Tim-MacBook Neo Talking节选.mp4`，同一机位/同一场景的另一种录制，用来演示被剪的口播。
- **B-roll 示例**：紫框画中画里的办公室举手机/麦克风、洞窟手持灯、黑卫衣举无人机手柄；以及课程后段的产品展示镜头（如 `橄榄色现场展示.mov`、`模特使用Neo日常视频.mov`）。这些是课程自带素材，不是本仓库可分发的内容。

本课的核心不是“记住按钮”，而是建立一条可复用的判断链：**先看波形找候选 → 再判断语义是否可删 → 用智能工具做粗剪 → 人工修补气口 → 铺 B-roll → 统一声音 → 字幕兜底 → 最后加 BGM 与导出**。

  这些 token 同时出现在句子里，说明工具会把停顿和语气词显式标出来，供人删除。
- **同步删除**（05:14–05:22）：在左侧删字后，下方视频片段同步缩短；画面可见片段长度变化。讲师把这种“改作文式”的流程称为“语义化剪辑”。
- **AI 局限**（05:22–05:42）：讲师明确说“AI 识别出来的内容不一定是完美的”；有的气口保留下来衔接更自然，不能一律删。两个气口挨得过近时，听起来会显得“很着急”，需要自己拉开距离。
- **接缝修补**（05:50–06:08）：
  1. 在两个音频段之间分割；
  2. 拖动音频块右上角小把手，指针旁提示“0.1s”；
  3. 给前后两段添加一个小小的叠化；
  4. 从房间安静段取一小块底噪，放到第二轨，垫在接缝下面。
  画面只能证明“拖把手 + 出现 0.1s 提示 + 第二轨出现底噪片段”，不能证明最终叠化一定等于 0.1 秒，也不能证明听感一定变好。

### 3.5 B-roll 添加规则（09:02–10:56）

- **对齐口播节奏**：B-roll 结束时要让口播的话说完；否则会出现“漏字”的观感（09:08–09:20）。
- **优先换长素材**：如果 B-roll 太短，最直接的解法是在上层轨道找一条长度更合适的素材，拖下来替换（09:20–09:34）。
- **成组添加**：同一主题用不同景别、不同角度的多条 B-roll 组成“镜头组”，比单条更完整；但讲师也承认这是“最理想的状态”（09:34–09:46）。
- **硬切遮蔽**：有些气口剪辑点无法被 B-roll 覆盖，硬切会突兀。方法一是把 A-roll 画面放大，制造“另一个机位”的错觉，从而把卡顿镜头连在一起；方法二是使用与主题相关的“万能 B-roll”空镜/展示素材填补空白（09:46–10:22）。
- **避免重复**：同一条/长得一模一样的 B-roll 不要反复出现；尽量选择不同镜头（10:22–10:34）。
- **同轨 + 一键静音**：B-roll 通常无声，建议全部放在同一条轨道，点击轨道最左侧“静音”图标，一次性静音所有 B-roll（10:34–10:56）。

## 五、可提炼的剪辑知识

- [画面] 素材分类树：`年份-月份-日期_项目名字 / 导出（成片、小样）/ 视频（其他素材、Aroll、Broll）/ 图片（包装设计素材、图片素材）/ 音频（音效、BGM）`。这是课程建议，不是平台规范；它的价值在于把“检索单位”从单个文件提升到项目/素材类型。
- [画面] 口播粗剪的最小闭环：先看波形找候选 → 播放头对准候选起点 → `Command+B`/`Control+B` 切第一刀 → 在候选结束处再切一刀 → 选中中间段删除。画面中反复出现“两刀删中间”的结构。
- [画面] 波形占比调到 60% 后，停顿/卡顿更容易被看见；但平波形只是候选，不能自动等于“可删”。讲师随后仍要求边听边判断重复、口误与表达完整性。
- [字幕] 智能剪口播会把“停顿”和“语气词”显式标注（如 `停顿 [...0.2s]`、`语气词 这个`），删除文字稿中的 token 会同步删除对应视频片段；它适合做第一轮粗剪，不适合直接交付。
- [字幕] AI 识别不完美：有的气口保留下来衔接更自然；两个气口挨得太近会显得“很着急”；需要人工拉开距离或补一小段叠化。
- [画面] 接缝修补的三件套：分割成前后两个音频段 → 拖动音频把手加一个小叠化（拖动时提示 0.1s）→ 在第二轨垫一小段房间底噪。画面能证明操作与轨道位置，不能证明最终听感。
- [画面] A-roll 放在主轨，B-roll 叠在其上；B-roll 是“丰富视觉 + 补充说明”，不是替代主叙事。示意图中 B-roll 与 A-roll 的时间位置一一对应。
- [画面] “B-roll 筛选器”：新建时间线02，把时间线01（A-roll）与时间线02（B-roll 候选）上下叠放；B-roll 全部并列铺开，播放 A-roll 时在上层扫视、裁切、拖下。它把“逐条点开预览”变成“横向扫一条素材带”。
- [画面] B-roll 结束点要服从口播语义：B-roll 太短会让最后一句话“漏字”；优先换一条更长的素材，而不是硬把 B-roll 拉长或让画面提前切走。
- [画面] B-roll 成组使用：同一主题的不同景别、不同角度组合成“镜头组”；避免重复使用长得一模一样的镜头。
- [画面] 硬切无法被 B-roll 覆盖时，有两种遮蔽：放大 A-roll 画面制造“第二机位”错觉；或用与主题相关的“万能 B-roll”空镜/展示素材填补。
- [画面] B-roll 通常无声，建议全部放同一条轨，用轨道左侧“静音”图标一键静音；这比逐条音量归零更不易漏。
- [画面] 补录面板的关键项：输入设备、输入音量 100、回声消除/草稿静音/人声美化。演示中三项默认开启，但讲师为了“最自然的原声”把它们关闭；这说明默认值不等于推荐值。
- [字幕/画面] 麦克风距离与防喷麦：不能太近（喷麦），不能太远（声音虚）；有线耳机/麦克风可套袜子或织物。前期解决优于后期降噪。
- [画面] 响度统一在音频参数“基础”里，和音量、淡入/淡出同区；演示中音量 0.0dB、淡入/淡出 0.0s。讲师明确说统一响度通常要等所有剪辑、BGM、音效完成后再做。
- [画面] 声道配置只有三个选项：无、左填右、右填左。它是“缺一个声道”的补救，不是立体声美化；检查方式是戴耳机听左右耳。
- [字幕] 字幕识别要放在 BGM 之前：识别会把时间线中所有音频片段都纳入，先加 BGM 可能影响识别结果。识别入口在“字幕 → 智能识别”，源语言“自动检测语言”，需要 VIP。
- [字幕/画面] 字幕默认联动：调整一段字幕的参数，其他段一起变；位置放在画面中心下方、避开边缘；字体演示值为 `思源黑体 CN`、字号 `5`、白色、字间距/行间距 `0`；阴影最终 `59% / 7% / 5 / -45°`（黑色）。这些是课程演示预设，不是通用审美标准。
- [画面/字幕] 安全区：用“16:9视频播放安全区”参考图检查字幕是否会被平台 UI 遮挡；字幕首尾要拉长衔接，避免空档。
- [画面] BGM：选曲后先裁到视频结束，再把音频末端白色圆点向左拖，形成下降斜坡淡出；斜坡是音量包络的可见证据，但听感仍需实际播放。
- [画面] 导出演示值：`原始 3840×2160 / MOV / 30fps / 50000 Kbps / H.264 / AAC 320 kbps / 48000 Hz`。这是课程当时的演示预设，不能直接当成所有平台的交付规范；发布参数应另查平台当前要求。
- [推论] 这套流程的可复用骨架是“先把叙事骨架剪干净，再铺视觉，再统一声音，最后用字幕/BGM/导出收口”；具体工具可以换，但顺序不应反过来。

- [待验] 本课只记录剪映界面路径，没有用 capcut-cli 实测；哪些步骤可由 CLI 复现、哪些必须回剪映界面，需另做工具验证。
