## 四、与旧笔记 / 字幕的差异

1. **码率表单位**：旧笔记怀疑 `KB/s` 是歧义；全分辨率帧确认表格确实印作 `KB/s`，而面板自定义字段用 `Kbps`。两者不一致是画面事实；不能自行把表格单位改成 Kbps 后当官方值使用。
2. **旧笔记说“00:10:38 码率表”**：本课抽帧显示表格出现在 10:38.5–10:46，时间码一致；表格四行、五列全部可读（见 3.7）。
3. **旧笔记说“H.264 为课程建议的兼容性起点”**：画面支持这一点，编码器默认 H.264，说明写“最常见的压缩方式，更加通用”；字幕称“比较稳妥”。但同一课后面又切到 HEVC/H.265，说明“默认”不等于“唯一推荐”。
4. **旧笔记说“24/25/30/60 fps 是场景选择”**：画面进一步给出草稿设置的 24.00/25.00/29.97/30.00/50.00/59.94 六档；SRT 只提 24/25/30/60，漏掉 29.97/50/59.94。
5. **旧笔记说“00:10:50 单帧显示 4K/60/HEVC/PCM/48kHz 的演示设置”**：那是第 03 课的旧核对；本课（07）的演示面板主要是 4K 或 1080P、30 fps、HEVC/H.264、PCM 或 AAC、48000 Hz。两者不是同一课同一状态，不能混用。
6. **SRT 误字（按画面修正）**：
   - `A c 192kilobits Per second` → 画面 `AAC 192 kbps`
   - `A c 256kilo bits per second` → 画面 `AAC 256 kbps`
   - `AAC320kb per second` → 画面 `AAC 320 kbps`
   - `kilo bieper second` → 画面 `kbps`
   - `H64` / `H65` → 画面 `H.264` / `H.265`
   - `48000HZ` → 画面 `48000 Hz`
   - `简易里面` → 画面/语境 `剪映里面`
   - `手动选择一个竞争` → 语境应为“一帧”；画面在 01:29–01:40 显示的是封面选帧界面，没有“竞争”字样
   - `EXEXPORT成片` → 画面文件夹 `Export 导出`
   - `PCM无损`、`AAC` 等术语应以画面为准
7. **命名写法自相矛盾**：输入框 `2026_01-10_…`，烧录大字 `2026-01-10_…`，最终导出弹窗 `2026-01-10_…`。课程没有说明哪种分隔符是规范；只能记录“课程演示同时出现过两种写法”。
8. **08:15–08:23 字幕与面板冲突**：字幕说“默认就选择4K”，面板字段显示 1080P，下拉里 1080P 有勾选、4K 只是悬停。不能把这一拍当作“已选 4K”的证据。
9. **13:50 的“1分2秒 / 117 MB”**：与 42 秒 / 138 MB 的工程读数不一致；可能是另一个导出结果或另一版工程。旧笔记没有提到这一点，本次只记录差异，不强行统一。
10. **封面入口**：旧笔记只提到“单独选封面”，画面补充了时间线最左端的暗色封面图标（02:14.5）和“封面设计”模板/文本页签（01:52.5）。

## 五、可提炼的剪辑知识

以下只写画面与字幕共同支持的内容，并区分证据来源。所有参数都是“课程演示设置”，不是平台规则或通用预设。

- [画面] 默认封面取视频第一帧；本课演示的首帧是黑场，因此需要手动“前往选择”。选帧时可拖动播放头，选择人物表情自然、景色完整或最能代表内容的定格。
- [画面] 封面可在导出面板里选择/上传，也可在时间线最左端的封面图标进入；封面设计提供“模板 / 文本”两类入口，模板会自动套文字，仍可改字、调尺寸、裁切。
- [字幕] 封面判断标准：有张力、简洁、能吸引点击；这是课程经验，不是平台算法规则。
- [画面] 命名示例：`日期_片名_分辨率_版本_平台`；课程演示为 `2026-01-10_混剪教学_4k_成片1_抖音`（输入框另有 `2026_01-10_…` 写法）。
- [字幕] 建议从第一个导出文件就按统一逻辑命名，避免“最终版2/3/再也不改”；这样能一眼看出日期、内容、分辨率、成片/过程稿、版本和平台。
- [画面] 归档结构：项目总文件夹 `年份-月份-日期_项目名字`，下设 `导出/成片/小样`、`视频/其他素材/Aroll/Broll`、`图片/包装设计素材/图片素材`、`音频/音效/BGM`。
- [字幕] 工程、素材、成片放在同一项目文件夹，便于迁移后找回；[旧笔记] 但“整体移动后自动恢复路径”不是绝对保证，迁移后仍应验证重链接（旧笔记第 03 课已提醒）。
- [画面+字幕] 分辨率：1080P=1920×1080（竖屏 1080×1920）；4K/UHD=3840×2160（竖屏 2160×3840）；按源素材上限选择，1080P 素材强行导出 4K 不会增加真实细节，只会增大文件。
- [画面+字幕] 帧率：24 帧偏电影感，25/30 帧为常见标准，60 帧适合运动；草稿设置可选 24.00/25.00/29.97/30.00/50.00/59.94 帧/秒；导出默认与草稿一致。
- [画面+字幕] AI 超分/补帧：一键超清、补分辨率、智能补帧（限免）能提升观感锐度或帧数，但会产生纹理伪影、过度平滑、拖影和“AI 脑补”错误；适合单段素材补救，不替代前期拍摄。画质上限由源素材原始分辨率和帧率决定。
- [画面+字幕] 码率：影响信息密度和文件体积；越高不一定越好，平台通常会二次压缩；课程通常选“推荐”或手动输入；参考表给出平台/分辨率/帧率对应的档位和范围，但单位存在 `KB/s` 与 `Kbps` 的不一致。
- [画面+字幕] 容器与编码：MP4/MOV 都可作为互联网平台交付容器；H.264 兼容性最好、导出快；HEVC=H.265 压缩效率更高、导出更慢、老设备兼容性差；还有 HEVC Alpha 与 ProRes 422/LT/HQ 等专业选项。
- [画面+字幕] 音频：AAC 192/256/320 kbps 与 PCM 无损四档；短视频常用 256/320 kbps；采样率 48000 Hz；可单独导出音频（MP3 320 kbps / 48000 Hz），也可导出 WAV、GIF 320P、SRT（UTF-8）。
- [画面+字幕] 导出前检查：面板底部“会员权益：N 项”提示使用了多少 VIP 功能；未开通可能无法导出含 VIP 功能的画面；是否开通按剪辑频率和工具习惯判断。
- [推论] 对 Skill 的可执行落点：把“封面、命名、归档、分辨率、帧率、码率、容器、编码器、音频、会员检查”做成导出前逐项核对清单；具体数值只作为“课程演示值/参考档位”，执行时必须重新读取当前工程与当前剪映版本，不能硬编码 4K、30 fps、HEVC、PCM 或 9600 Kbps。
- [待验] 平台现行码率上限、二次压缩策略、封面尺寸/比例、会员素材清单、剪映当前版本的导出面板字段，都需要另查官方资料或用当前版本实测，不能引用本课画面作为现行规则。
