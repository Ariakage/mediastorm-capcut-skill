## 三、关键画面与参数

### 1. 自由层级的两种打开方式（01:06 / 01:14）

- 新建草稿对话框：`自由层级` 开关开启，下方黄字“*自由层级开启并保存后不可关闭。”
- 全局设置 → 剪辑 → `自由层级` 开关，说明文字“新建草稿时，默认开启自由层级”。
- 同页可读：时间线大幅移动 `10 帧`、数值大幅调节 `10 单位`、图片默认时长 `5.0 秒`、目标响度 `默认 -23LUFS`、默认分辨率“与轨道首个素材相同，最低1080P”、默认帧率 `30.00帧/秒`、时码样式 `HH:MM:SS + 帧`。
- [画面] 这是本课所有“上下层自由摆放”的前提；它只影响新草稿的默认值，不是抠像算法参数。

### 2. 智能抠像（01:52–02:05）

- 路径：选中片段 → 右侧 `画面` → `抠像` → `智能抠像`。
- 可见参数：`羽化 0`、`边缘缩放 0`、`抠像描边`（折叠，未勾选）。
- 结果：人物被单独保留，背景透明；预览显示黑底。
- [画面] 课程全程未演示“羽化/边缘缩放”非零值，也没有展开“抠像描边”。

### 3. 自定义抠像（02:36–03:34）

- 工具行：`智能画笔` / `智能橡皮` / `画笔` / `橡皮擦`。
- 参数：`大小 20`、`羽化 0`、`边缘缩放 0`；右下角 `应用效果`。
- 操作：智能画笔粗涂 → 自动扩选 → 调小笔刷/换普通画笔补涂 → 智能橡皮擦掉多余 → 蓝色覆盖完整 → 应用。
- 反馈：应用后右上角显示“处理中 12%”，随后生成透明独立层。
- [画面] 蓝色高光是“保留区”的可视化，不是最终颜色。

## 五、可提炼的剪辑知识

1. **按素材类型选工具，而不是按“效果强弱”选工具。** [画面] 课程把智能抠像、自定义抠像、色度抠图、蒙版、混合模式并列成五种处理路径；[字幕] 日常素材用智能抠像，边缘不干净用自定义抠像，绿幕用色度抠图，画面外穿帮用蒙版，黑白特效素材用混合模式。课程对“发丝”有两种说法：开头把自定义抠像描述为处理发丝边缘，后半段又说发丝飘逸/细节丰富时前两种不够用、需要色度抠图；[推论] 关键不在“有没有发丝”，而在素材是否有可控纯色背景。
2. **智能抠像后必须沿运动检查。** [画面] 课程用预览轴快速划轨，专门看“残留背景”和“误删主体”；[推论] 单帧干净不代表整段可用，尤其发丝、快速挥手和边缘逆光。
3. **自定义抠像的蓝色高光是选区，不是效果。** [画面] 蓝色覆盖处=保留区；智能画笔先粗选，智能橡皮再擦除；[推论] 修正一帧后仍需回到整段播放检查算法传播。
4. **色度抠图是“选一种颜色剔除”，不是“识别主体”。** [画面] 取色器吸取绿色后只保留人物；[字幕] 阈值默认较窄，深/浅绿会残留；[推论] 光照不匀的绿幕需要强度、阴影、羽化、清除分步调，不能只拉一个滑块。
5. **阈值不是越大越好。** [画面] 拉满后画面出现大片黑色缺口；[推论] 判断标准是“边缘干净且主体完整”，不是“绿色像素归零”。
6. **边缘羽化和边缘清除解决的是不同问题。** [画面] 羽化让边缘柔和，清除针对残留绿边；[推论] 羽化过度会让主体边缘发虚，不能用它掩盖错误的阈值。
7. **绿幕面积不足时，蒙版是“裁掉穿帮”的工具。** [画面] 圆形蒙版尺寸大于画面，遮住绿幕外的灯架；[推论] 蒙版只能隐藏，不能补出缺失的背景，人物仍须留在绿幕覆盖范围内。
8. **图层顺序决定“三明治”是否成立。** [画面] 抠像层在上、文字层在中、背景层在下；[字幕] 复制同一片段到辅轨并对齐，再禁用主轨做检查；[推论] 复制层必须与背景时点同步，否则人物和背景会错位。
9. **混合模式是颜色融合，不是精确透明通道。** [画面] 白底黑颗粒用变暗组、黑底白条纹用变亮组、需要半透明融合用叠加/柔光；[字幕] 口诀“留白用变亮、留黑用变暗、融合用叠加”；[推论] 混合模式不能替代色度抠图，遇到彩色背景或需要精确 alpha 的素材仍应走抠像。
10. **工具边界。** [工具][待验] 本机 `capcut-cli` 的 `matting` 只写智能抠像配置 flag；本次课程画面证明的是剪映界面里的像素结果，不能反推 CLI 已完成像素计算、发丝质量或导出验收。若要复用，必须在剪映界面实际打开草稿并检查整段运动。
