## 一、本课定位

这是全课程第一条**完整操作线**，也是结构板上的“第一节课”。它用一条练习素材走通：

> 安装/登录 → 导入素材 → 选片与预览 → 加到时间线 → 用播放头逐帧定位 → 分割并删除首尾抖动 → 打开自由层级 → 第二段素材的两种放置方式 → 主轨/副轨与主轨磁吸 → 继续加片 → 缩放时间线 → 加 BGM → 自动踩节拍并对齐剪辑点 → 降低预览画质 → 代理模式 → 导出。

画面由讲师口播、剪映桌面端录屏和大量动态图解组成。录屏主要在 macOS 上完成，Windows 只出现在快捷键口播和官网安装包画面里。与第 02 课不同，本课真正操作了时间线：有明确的片段时间码、切点、轨道层级和导出参数。

课程编号需要注意：本课是结构板上的“第一节课：初试成片”，对应实际文件编号 03；引用时不要和实际文件 01 的宣传片混淆。

## 五、可提炼的剪辑知识

- [画面] 本课给出了一条可复现的最小闭环：导入 → 选片 → 预览 → 上轨 → 逐帧定位 → 分割 → 删除 → 排列 → 加 BGM → 卡点 → 预览优化 → 导出。
- [画面] 分割用播放头定位 + `Command+B`（Win `Ctrl+B`）；本课先切头 `00:00:03:08`，再切尾 `00:00:24:17`，保留 `00:00:21:09`，数值可以复算。
- [画面] 第二段素材有两种放置结果：接在主轨后方 = 先后播放；拖到上方轨道 = 时间并列、画面重叠，课程称为“画中画”。
- [画面] 纵向层级：越靠上的轨道在画面中越靠前；最下层是主轨，其余是副轨/辅轨。
- [画面] 主轨默认首尾相接、删除后自动前移；关闭“主轨磁吸”后主轨可以像副轨一样自由摆放。这个设置会改变编排行为，操作前应确认。
- [画面] 时间线可 `Ctrl/Cmd + 滚轮` 缩放；素材多时先缩放到能看全，再做整体排列。
- [画面] BGM 与视频素材一样拖入；音频轨出现在主轨下方，左侧有音频标识、锁、眼睛、音量、S 等控制。
- [画面] 自动踩点提供 `踩节拍I` / `踩节拍II` 两档密度；标记点只是候选坐标，仍需逐段把片段头/尾拖到标记点对齐。
- [画面] 预览卡顿时先降清晰度（原画质 → 清晰画质 → 流畅画质），再考虑代理；代理分辨率可选 `720P` / `540P`，导出自动回原始素材。
- [画面] 导出至少涉及：标题、导出至、分辨率、格式、帧率、码率、编码、音频质量、采样率、色彩空间。课程演示值为 4K / MP4 / 60 fps / 更高码率 / HEVC / PCM 无损 / 48000 Hz / Rec.709 SDR。
- [画面] 本课在 05:40–05:50 打开“自由层级”，字幕称其为“编排时间线的关键”。这是课程演示设置；当前版本是否仍需先开、以及它对主轨/副轨的具体影响，需在剪映界面实测。
- [字幕] 自动踩点在本课中被描述为“快速增添节奏感”的工具；它不替代对音乐段落和镜头内容的判断。
- [推论] 对 Skill 而言，应把“先定可用区间，再切头尾”写成判断流程：先看素材哪里稳定、哪里可用，再用播放头逐帧确认切点；不要反过来先切再找。
- [推论] “主轨磁吸”与“自由层级”都是会改变工程行为的设置，适合做成开工前检查项，而不是默认一律打开/关闭。
- [待验] 代理模式是否对所有素材自动生成、生成时机与磁盘占用；本课只展示了开关和分辨率，没有展示生成过程与耗时。
- [待验] 自动踩点的标记是否可手动增删、能否吸附；本课只展示对齐动作。
- [待验] 导出参考表的“60”是推荐帧率还是示例值；UI 初始 30 fps，说明表格不是强制预设。
