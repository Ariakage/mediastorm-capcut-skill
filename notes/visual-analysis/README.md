# 全课程细粒度画面解析索引

来源：影视飓风（MediaStorm）付费剪映教学课程，个人学习整理，非官方。
方法：对每个视频按 **2 秒间隔**抽帧，组成带时间码的 2×2 索引页（单格 960×540），逐张查看；界面参数看不清时再用全分辨率定点抓帧放大。抽帧清单保存在被忽略的 `cheese/.analysis/fine/<课号>/manifest.json`。

## 证据边界

- 本目录记录的是**按 2 秒采样的画面观察**，不是逐帧解码，也不是连续视频输入。
- 没有音轨听辨，不能据此评价音乐、音效、语气、混响或左右声道。
- 烧录字幕、界面文字与 SRT 冲突时，以画面为准并记录差异；看不清的数值标“部分可见/看不清”。
- 课程演示参数是案例值，不是通用预设；平台规则需另行核对当前官方资料。
- 所有原始视频、字幕、索引页都不进入 Git。

## 复现方法

生成某课索引页：

```bash
cheese/.analysis/.venv/bin/python scripts/fine_frames.py sheets 03 --interval 2 --out cheese/.analysis/fine --clean
```

按时间点抓全分辨率帧（可裁剪放大）：

```bash
cheese/.analysis/.venv/bin/python scripts/fine_frames.py grab 03 05:12.5 --crop 1420:100:500:800 --scale 1600
```

生成后用 Read 工具逐张查看 `cheese/.analysis/fine/<课号>/sheet-*.jpg`；`manifest.json` 记录每张索引页对应的源时间戳。
