## 一、本课定位

这是一节**“拉片 + 工作流演示 + 操作教学”混合课**，不是单一软件功能教学。画面主体分为六块：

1. 讲师 Tim 在书桌前口述本课目标，并插入课程片头（00:00–00:44）。
2. 播放“加州样片日记”成片片段，作为后续拉片对象（00:44–01:06、03:38–03:58 等）。
3. 用 Finder、DaVinci Resolve 工程管理器和剪映素材库演示**素材目录、命名与归档**（01:06–03:12）。
4. 在剪映专业版中新建拉片时间线，用“智能镜头分割”拆镜头（03:12–03:38）。
5. 用思维导图、时钟理论讲解 **Vlog 的叙事结构**，并演示“旁白 + 节奏点”两种串联方式（04:08–10:20）。
6. 在“进阶调色”章节演示 **RGB 曲线、色彩克隆、智能调色、LUT 与导出目录**（10:20–14:08）。

课程口播称“第14节课”，这是宣传板编号；按实际文件编号为第 16 课。核心产出是一个可复用的样片日记工作流：素材整理 → 拉片/拆镜头 → 思维导图 → 分段剪辑 → 旁白/节奏点串联 → 调色 → 小样与成片分目录导出。

## 五、可提炼的剪辑知识

- [画面] 素材目录先按“日期 + 项目名”建总文件夹，再按工作流拆子文件夹；子文件夹前加两位数字，可让系统稳定按剪辑顺序排列。课程示例：`2026-02-03-加州样片日记` + `01_工程文件…09_归档`。
