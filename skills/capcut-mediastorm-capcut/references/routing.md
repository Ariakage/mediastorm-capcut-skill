# 路由矩阵

本参考把用户请求映射到子 Skill。入口只负责识别目标、组合顺序和证据边界，不承载所有细节。

## 先判断交付形态

- 如果只是改 CapCut 草稿里的字幕、时间、速度、音量或普通素材，优先使用现有 `capcut-edit` 的通用能力；本组合 Skill 负责编辑判断和验收。
- 如果请求涉及“为什么这样剪、如何判断、怎么验收”，使用本组合 Skill。
- 如果请求要求上传私有素材、调用云端 AI、消耗积分、发布内容或覆盖磁盘状态，先停下来取得明确授权。

## 子 Skill 路由

| 用户目标或材料状态 | 路由 | 不应误判为 |
| --- | --- | --- |
| 素材能否导入、编码/帧率不明、媒体离线、目录混乱、代理卡顿 | `capcut-mediastorm-project-prep` | 叙事问题 |
| 视频讲不清、段落顺序、信息密度、B-roll 是否服务叙事、长短片节奏 | `capcut-mediastorm-story-structure` | 单纯卡点或转场 |
| 口播精剪、采访、take 选择、气口、字幕、多机位同步 | `capcut-mediastorm-dialogue-interview` | 音乐/音效设计 |
| 音乐收束、声音先行/延续、环境声、设计音效、尾音、响度意图 | `capcut-mediastorm-music-sound` | 对白语义取舍 |
| 慢放、加速、动作峰值、源帧率是否够、补帧风险 | `capcut-mediastorm-speed-time` | 普通关键帧动画 |
| 推近/平移、逐参数缓动、点跟踪标签、数字闪变、计时器 | `capcut-mediastorm-motion-graphics` | 平面跟踪或抠像 |
| 智能/色度抠像、蒙版、混合模式、图层遮挡、平面跟踪失效 | `capcut-mediastorm-compositing-tracking` | 调色或普通点跟踪 |
| Log 还原、示波器、曲线、跨镜头匹配、肤色和风格 | `capcut-mediastorm-color-grading` | 导出参数 |
| AI 生成 B-roll、概念镜头、局部生成特效、成本与真实性 | `capcut-mediastorm-generative-broll` | AI 选 take 或超分验收 |
| 封面、版本、导出、归档、手机/桌面接力、发布前检查 | `capcut-mediastorm-delivery-handoff` | 创作阶段 |

## 常见组合顺序

1. 口播短片：项目接入 → 语义粗剪/气口 → B-roll 结构 → 字幕 → 音乐/音效 → 交付。
2. 无对白混剪：项目接入 → 素材关系与段落 → 音乐/声音 → 变速/动态 → 色彩 → 交付。
3. 教程包装：项目接入 → 结构 → 参数动画/数字包装 → 空间跟踪/合成 → 声音 → 交付。
4. 采访：项目接入 → 多机位同步与主收音 → 语义剪辑 → 反应镜头与 B-roll → 字幕 → 交付。
5. 手机到桌面：手机初剪 → 可编辑草稿接力 → 桌面精修 → 跨端一致性 → 导出与归档。

## 路由输出

在动手前写出一句话路由，例如：

`项目接入 → 语义口播剪辑 → 声音桥 → 平面跟踪包装 → 交付检查。`

如果任何一步缺乏输入、授权或验证路径，把该步骤标为阻塞，不要跳过验收仍宣布完成。
