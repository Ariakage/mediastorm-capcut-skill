# 参数动画与信息动效

## 推近与缓动

- `[课程][08 01:00–02:40]` 参数属于片段；同一素材切成两段后不自动共享全部设置。
- `[课程][08 02:40–04:39]` 先确定动作起止与目标构图，再添加关键帧。
- `[课程][08 04:39–07:19]` 后期推进常同时改变缩放和位置；相关参数的起止时间应对齐。
- `[课程][08 07:19–10:01]` 缩放缓动而 X/Y 仍线性会导致节奏脱节；逐参数核对曲线。有意错开时记录设计意图。

## 点跟踪标签

- `[课程][12 06:19–08:49]` 选择稳定、对比明显且不易消失的特征；只要位置标签时避免无意继承缩放或透视。
- `[课程][12 09:19–10:57]` 先修剪可用镜头范围再追踪；移动标签要检查互遮和重要信息可读性。
- 00:08:24 的截图显示“距离”开关仍在调整，不能把过程值当最终设置。

## 数字闪变与计时器

- `[课程][12 12:48–14:35]` 数字闪变可由短文本片段构成；案例约每段 2 帧、8–10 个变化，末段保持最终值。
- `[推论]` 用项目帧率把时长换算成整数帧，避免毫秒累计漂移；最后一帧或最后一段必须停住可读。
- `[课程][12 14:35–17:29]` 向上出入场配对、同样式位置和局部蒙版可形成滚动窗口；约 0.4 秒只是案例节奏。
- `[课程][15 15:32–19:51]` 半透明背景、数字文本、进出动画和错位只是案例风格参数，不写死。

## 工具边界

- `[工具][capcut-cli 0.31.1]` `keyframe` 支持 batch 和 `linear/ease-in/ease-out/ease-in-out/hold`；easing 需要相邻同属性关键帧，hold 需要后续关键帧。
- 先前 capcut-edit 验证记录显示 macOS 路径下 alpha keyframes 不可靠；需要淡入淡出时优先评估 `image-anim` 或动画材料路径。
- `image-anim`、`text-anim`、`add-text` 均有 CLI 契约，但本组合 Skill 尚未对视觉效果做剪映界面验收。
- 检查相邻片段出入场、转场和覆盖轨道，避免把邻居效果误判成目标动画。

## 验收

- 构图起止正确，运动可读。
- 每个参数的插值符合意图。
- 标签不遮挡主体、字幕或平台 UI。
- 数字变化按帧网格对齐，末值停留。
- 剪映重开后动画仍可见，代理预览不作为唯一证据。
