# 参数动画与信息动效

## 推近与缓动

- `[课程][08 01:00–02:40]` 参数属于片段；同一素材切成两段后不自动共享全部设置。
- `[课程][08 02:40–04:39]` 先确定动作起止与目标构图，再添加关键帧。
- `[课程][08 04:39–07:19]` 后期推进常同时改变缩放和位置；相关参数的起止时间应对齐。
- `[课程][08 07:19–10:01]` 缩放缓动而 X/Y 仍线性会导致节奏脱节；逐参数核对曲线。有意错开时记录设计意图。

## 归属澄清

- `[画面]` 第 08 课全课 82 张索引页只讲**关键帧、缩放/位置参数与曲线缓动**，没有点跟踪标签、数字闪变或计时器。
- 点跟踪/文字跟踪、设备标签、数字闪变、上下场动画在第 **12** 课；计时器包装在第 **15** 课；平面跟踪在第 **13** 课。不要把四者写成同一能力。

## 关键帧与缓动（08）

- `[画面][08 05:58.5 / 06:22.5]` 手机推近案例终点为缩放 `286%`、位置 X `0`、Y `-2219`；起点为缩放 `100%`、位置 `0/0`。01:46.5 的 354% 和 05:12.5 的 214% 是拖动中间值，不是最终预设。
- `[画面][08 07:59.0 / 08:20.5]` 右键菜单写作“显示关键帧变速曲线”；面板同时显示缩放、位置 X、位置 Y 三条曲线，刻度为缩放 `4.00–0.00`、X `768–-768`、Y `432–-2160`，默认都是直线。
- `[画面][08 09:18.5]` 缓动预设完整列表：`无 / 缓入 / 二次方缓入 / 三次方缓入 / 缓出 / 二次方缓出 / 三次方缓出 / 缓动 / 二次方缓动 / 三次方缓动 / 回弹展开 / 线性`；案例选 `二次方缓入`，并把三条曲线改成同一预设。
- `[待验][08 06:22.5]` 缩放行的菱形看起来是空心、位置行是实心，与“终点缩放关键帧已存在”有表面冲突，需更高分辨率或连续操作复核。

## 点跟踪标签（12）

- `[画面][12 08:24–08:26]` 跟踪面板有“缩放/距离”两个开关；本案例把它们关掉，文字只跟位置，不随人物远近变大变小。
- `[画面][12 06:19–08:49]` 选择稳定、对比明显且不易消失的特征；只要位置标签时避免无意继承缩放或透视。
- `[画面][12 09:19–10:57]` 先修剪可用镜头范围再追踪；移动标签要检查互遮和重要信息可读性。

## 数字闪变与计时器

- `[画面][12 12:48–14:35]` 数字闪变的设计单位是短文本片段；口播说“约 2 帧、8–10 个变化”，但完成片帧网格只稳定辨认出第一段 8 个值/15 帧（约 0.50s）、第二段 6 个值/11 帧（约 0.37s），单值 1–3 帧，**不是严格每段 2 帧**。末段保持最终值。
- `[推论]` 用项目帧率把时长换算成整数帧，避免毫秒累计漂移；最后一帧或最后一段必须停住可读。以完成片帧网格验收，不以口播数字代替。
- `[画面][12 14:35–17:29]` 向上出场/入场配对、同样式位置和局部蒙版形成滚动窗口；面板设置约 `0.4s`，但预览可见的两段数字同屏重叠约 5 帧（约 0.17s）。0.4s 是设置值，不等于可见重叠时长。
- `[画面][12 10:20 / 12:52 / 13:31]` 设备标签：字体 `JY-Glee`、字号 15、缩放 28%、白字、阴影 20%（阴影值来自 06:48–06:56 的文本面板）。价格文字：字体 `ZY Vigorous-Medium`、字号 15、加粗、居中、缩放 199%、X0 / Y2609、白字、黑色描边粗细 12；阴影不透明度连续读到 27%→50%→8%→10%，最终值[待验]。
- `[画面][15 16:30–19:47]` 计时器结构：黑幕素材 + 矩形蒙版 `538×540`、圆角 27、白色描边 2、阴影 `100/19/0/0`、画面不透明度 45%；文字字号 15、缩放 134%、文本阴影 `45/16/0/0`；复制六块背景 + 六个数字文本 + 向上滑动 + 倒阶梯错位 + 两次复合片段，最后保存为“我的预设2”。
- `[画面/字幕冲突][15 18:49–18:56]` 动画面板读数明确为 `0.5s`，同一帧口播/字幕说“0.3 秒左右”；在听辨或原工程确认前，不能把 0.3 秒当最终参数。

## 工具边界

- `[工具][capcut-cli 0.31.1]` `keyframe` 支持 batch 和 `linear/ease-in/ease-out/ease-in-out/hold`；easing 需要相邻同属性关键帧，hold 需要后续关键帧。
- 先前 capcut-edit 验证记录显示 macOS 路径下 alpha keyframes 不可靠；需要淡入淡出时优先评估 `image-anim` 或动画材料路径。
- `image-anim`、`text-anim`、`add-text` 均有 CLI 契约，但本组合 Skill 尚未对视觉效果做剪映界面验收。
- 检查相邻片段出入场、转场和覆盖轨道，避免把邻居效果误判成目标动画。

## 验收

- 构图起止正确，运动可读。
- 每个参数的插值符合意图。
- 标签不遮挡主体、字幕或平台 UI。
- 数字变化按帧网格对齐，末值停留。
- 剪映重开后动画仍可见，代理预览不作为唯一证据。
